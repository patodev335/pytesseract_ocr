# pytesseract_ocr
A simple OCR made with pytesseract.

Dependency List:
pytesseract
opencv-python


Pytesseract is an open-source Python wrapper for Google's Tesseract OCR Engine that extracts text from images and scanned documents

OpenCV (Open Source Computer Vision Library) is a massive, open-source software library packed with tools for real-time computer vision, image processing, and machine learning

PyTesseract and OpenCV are not competitors; they are complementary tools used together in Computer Vision. PyTesseract is a Python wrapper for Google's Tesseract, specifically designed for Optical Character Recognition (OCR) (converting text inside images into machine-readable strings). OpenCV, on the other hand, is a massive computer vision library used for comprehensive image and video processing (resizing, filtering, color conversion, and thresholding).
